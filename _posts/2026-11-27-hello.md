This is my personal site. Here I collect the projects I build and, from now on, write about them.

## What's here

- **[Projects](/projects/)** — a page for each project: what it is, how it works inside, how to try it.
- **Blog** — notes on building those projects: decisions, mistakes and things I learned along the way.
- The whole site in two languages: English and [Russian](/ru/blog/hello/).

## How the site is made

The site is static and lives on GitHub Pages under its own domain. Pages are built with Jekyll: a project or a post is a
Markdown file, and one layout turns it into a page. The look is a blueprint grid — JetBrains Mono, thin rules and one
orange accent.

## What's next

I plan to write about the projects in more detail: how the Pavlus template compiler works, how CS.Core checks code in a
sandbox, and how an agent works through comments left on a page. If you'd like to hear about something specific, write to me
on [Telegram](https://t.me/rysev_a).
