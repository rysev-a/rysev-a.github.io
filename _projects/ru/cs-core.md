## Что это

CS.Core — курс, который ведёт от дискретной математики и транзистора до проектирования собственного веб-сервиса. В каждой
главе — анимированные слайды, текст озвучки, тест по теории и практика прямо в браузере. Курс работает на
[cs-core.tech](https://cs-core.tech) в режиме пробного запуска на одной небольшой машине.

## Что внутри главы

- **Теория:** анимированные слайды, схемы в которых строятся из данных — ячейки, указатели, вентили, области, код.
- **Вопросы:** тест; правильные ответы знает только сервер.
- **Практика:** задачи на Python, JavaScript, SQL, C и Rust проверяются в песочнице без сети.
- **Лабораторные:** схемы из логических вентилей, ассемблер и RISC-V, симулятор сети, виртуализация, схема высоконагруженного
  сервиса, HTML и CSS. Решения лабораторных перепроверяются на сервере тем же кодом, что работает в браузере.

## Как устроено

```
browser (Leptos, wasm) ──► Traefik ──► frontend (Caddy, static files)
                                   └─► backend (axum) ──► SurrealDB
worker (Python) ──► dind ──► sandboxes (python, node, rust, gcc, sqlite)
```

Движки лабораторных — общие Rust-крейты, которые работают и в браузере (wasm), и на сервере. Playwright-тесты покрывают
каждую книгу и лабораторную, а всю систему можно запустить из готовых образов.
