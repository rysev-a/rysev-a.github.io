Pavlus

Framework

An isomorphic web framework built around messages, effects and plugins. It has its own template compiler and Vite plugin, SSR, and a server runtime with http, ws, Postgres and Redis plugins. It also comes with a shadcn-based UI kit, a devtools panel and a Zed extension.

Learn Music

Learning app

A browser app for learning to read sheet music. It renders the score, plays it back with a tempo you set, and checks what you play note by note. Exercises are built bar by bar from real pieces, like Carcassi's Op. 60.

Education platform

An audio course on programming, "from zero to your own web service": 12 books and 316 chapters, from discrete maths and computer architecture to Rust, databases and system design. Each chapter has animated slides, quizzes, sandboxed code checks and interactive labs.

AI Comments

Server + extension

Select an area of a page, write what to change, and an AI agent picks it up. It edits the code and reports progress back to the same page, live. Comments go through a kanban board (draft → sent → processing → done) with threaded replies. It runs on a server, with a browser extension.
